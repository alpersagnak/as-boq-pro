KURULUM
1. Çalışan terminalde Ctrl+C yapın.
2. ZIP'i açın.
3. AS_BOQ_PRO_v4_2 klasörünün İÇİNDEKİ bütün dosyaları kopyalayın.
4. Şu klasöre yapıştırın:
   C:\Users\alper\Documents\GitHub\as-boq-pro
5. "Hedefteki dosyaları değiştir" seçin.
6. VS Code terminalinde:
   npm install
   npm run dev
