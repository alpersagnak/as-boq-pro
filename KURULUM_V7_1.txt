A.S BOQ PRO v7.1 - İLİŞKİSEL SUPABASE KURULUMU

1) Mevcut proje klasörünüzün yedeğini alın.
2) Bu paketteki dosyaları mevcut as-boq-pro klasörüne kopyalayın ve değiştirin.
3) .env dosyanızı SİLMEYİN ve üzerine yazmayın.
4) Supabase > SQL Editor > New query açın.
5) supabase_v7_1_relational.sql içeriğinin tamamını yapıştırıp Run'a basın.
6) VS Code terminalinde çalışan Vite'ı Ctrl+C ile durdurun.
7) npm install
8) npm run dev
9) Tarayıcıda Ctrl+F5 yapın.

İLK AÇILIŞTA:
- v7 sürümündeki tek-parça asboq_app_state kaydı bulunursa otomatik olarak yeni tablolara aktarılır.
- Projeler asboq_projects tablosuna,
- BOQ satırları asboq_boq_items tablosuna,
- Hakedişler asboq_progress_payments tablosuna kaydedilir.
- Yerel kayıt yedek olarak tutulmaya devam eder.

Kontrol:
Supabase Table Editor'da asboq_projects ve asboq_boq_items tablolarında veriler görünmelidir.
