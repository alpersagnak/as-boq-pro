A.S BOQ PRO v7.5.1 – PROFİL VE DUVAR GENİŞLİĞİ GÜNCELLEMESİ

YENİLİKLER
- Galvaniz profil / siyah profil seçimi
- Karkas-duvar genişliğini kullanıcı girişi ile belirleme
- Profil et kalınlığını serbest girme
- Seçime göre reçete malzeme adlarının otomatik değişmesi
- Yaklaşık bitmiş duvar kalınlığının otomatik gösterilmesi

KURULUM
1. Mevcut proje klasörünüzün yedeğini alın.
2. ZIP içindeki dosyaları mevcut as-boq-pro klasörüne kopyalayın.
3. Dosyaları değiştirmeyi onaylayın.
4. Mevcut .env dosyanızı koruyun.
5. npm install
6. npm run dev
7. Tarayıcıda Ctrl + F5 yapın.

Ek Supabase SQL işlemi gerekmez.
