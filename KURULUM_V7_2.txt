A.S BOQ PRO v7.2 - EXCEL HIZLI GİRİŞ

YENİLİKLER
- Excel'den kopyalanan satırları Panodan Yapıştır ile BOQ'ya toplu ekleme
- BOQ hücre düzenlemelerinde Geri Al / İleri Al düğmeleri
- Mevcut Supabase otomatik kayıt ve ilişkisel tablolar korunur
- Sürüm etiketi v7.2 olarak güncellendi

KURULUM
1. Mevcut as-boq-pro klasörünüzün yedeğini alın.
2. Bu paketteki dosyaları mevcut proje klasörüne kopyalayın.
3. .env dosyanızı silmeyin; paket gerçek .env içermez.
4. Terminalde npm install ve npm run dev çalıştırın.
5. Tarayıcıda Ctrl+F5 yapın.

PANODAN YAPIŞTIR KULLANIMI
Excel sütun sırası başlıksız kullanımda:
Poz No | İş Kalemi | Birim | Kategori | Miktar

Başlıklı tablo da desteklenir. Tarayıcı ilk kullanımda pano izni isteyebilir.
