A.S BOQ PRO v7.5.2 - Canlı Kesit ve Şablonlar

1. Mevcut proje klasörünüzün yedeğini alın.
2. ZIP içeriğini mevcut as-boq-pro klasörüne kopyalayın.
3. .env dosyanızı koruyun.
4. Terminalde npm install ve npm run dev çalıştırın.
5. Tarayıcıda Ctrl+F5 yapın.

Yeni özellikler:
- Galvaniz ve siyah profil hazır kesit kütüphanesi
- Kullanıcı girişli profil derinliği, yüz genişliği ve et kalınlığı
- Canlı duvar kesiti
- Yaklaşık bitmiş duvar kalınlığı
- Akıllı teknik ön uyarılar
- Duvar reçetelerini yerel şablon olarak kaydetme ve tekrar kullanma

Ek Supabase SQL işlemi gerekmez.
