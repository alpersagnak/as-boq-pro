A.S BOQ PRO - SUPABASE BULUT SÜRÜMÜ KURULUMU

1) Supabase panelini açın.
2) SQL Editor > New query bölümüne girin.
3) Paket içindeki supabase_setup.sql dosyasının tamamını çalıştırın.
4) Proje ana klasöründeki .env dosyanızda şunlar bulunmalı:

VITE_SUPABASE_URL=https://PROJE_ID.supabase.co
VITE_SUPABASE_ANON_KEY=PUBLISHABLE_KEY

5) Terminalde proje klasöründe çalıştırın:

npm install
npm run dev

6) Tarayıcıda üst bölümde şu durum görünmelidir:
"Supabase senkronize"

Notlar:
- İlk açılışta mevcut localStorage verileri otomatik olarak Supabase'e yüklenir.
- İnternet veya ayar sorunu varsa program yerel kayıt modunda çalışmayı sürdürür.
- Veriler hem tarayıcıda hem Supabase'de tutulur.
- Geliştirme RLS politikası anon erişime açıktır. Kullanıcı giriş sistemi eklenirken user_id bazlı güvenlik uygulanmalıdır.
